---
title: Several apps
description: Run every app of a project together with aka.toml and aka up.
---

List the apps in an `aka.toml` at the project root:

```toml title="aka.toml"
[apps]
web = "npm run dev"
api = "uvicorn main:app --reload"

[apps.worker]            # a table for more settings
cmd = "python -m worker"
dir = "services/worker"  # relative to aka.toml
port_hint = 9000         # optional, like --port-hint
no_preset = false        # optional, like --no-preset
```

Then run them:

```bash
aka up            # every app
aka up web api    # some of them
aka               # a bare aka in the project runs aka up
```

Each app gets its own URL (`web.localhost`, `api.localhost`), preset and port detection, and its output is prefixed with its name. Ctrl+C stops them all. `aka up` keeps running until every app has stopped, and then exits with the status of the first app, by name, that failed, or 0.

A command that uses shell syntax (`a && b`, `$VAR`, `>`) runs through `sh -c`, or `cmd /c` on Windows. Other commands are split into words, with quotes honoured, so presets can see them.

See [Configuration](/docs/configuration#akatoml) for every setting.
