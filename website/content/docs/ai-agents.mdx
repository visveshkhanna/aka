`aka mcp` is a [Model Context Protocol](https://modelcontextprotocol.io) server over stdio. A coding agent can use it to look up the URL of the app it is working on instead of guessing a port.

## Set it up

For Claude Code:

```bash
claude mcp add aka -- aka mcp
```

For other MCP clients, add it to the client's configuration:

```json
{ "mcpServers": { "aka": { "command": "aka", "args": ["mcp"] } } }
```

## Tools

| Tool | What it does |
|---|---|
| `list_apps` | the running apps and aliases, with their URLs |
| `get_url` | the URL of one app |
| `add_alias` | route a name to a port |
| `remove_alias` | remove an alias |
| `doctor` | run the setup checks |

The server does not start dev servers. Agents run `aka <name> <command>` in a shell.
